# Plankton Academic Korean Speaking

Build the initial frontend of a web application called PLANKTON.

PLANKTON is an AI-powered academic Korean speaking platform designed for international students studying at Korean universities.

The main purpose is to help international students improve their Korean speaking skills through academic conversations, presentation practice, professor Q&A simulations, and personalised feedback.

IMPORTANT:
For this first stage, focus ONLY on the website design, page structure, navigation, and user experience. Do not implement authentication, databases, payment systems, or real AI integrations yet.

DESIGN DIRECTION:
- Modern, clean, premium EdTech SaaS design.
- Ocean-inspired colour palette using deep navy, teal, light blue, and white.
- Professional but friendly.
- Rounded cards, clean typography, subtle shadows, and consistent spacing.
- Fully responsive for desktop and mobile.
- Easy to navigate for international students.

CREATE THESE PAGES:

1. LANDING PAGE
- Plankton logo.
- Slogan: "From Understanding Korean to Speaking It Confidently."
- Short explanation of the problem faced by international students.
- Four feature sections: Academic Speaking, Presentation Simulator, Professor Q&A, and Personalised Feedback.
- How it works section.
- Pricing preview.
- Get Started button.

2. DASHBOARD
- Welcome message.
- User profile card.
- Korean proficiency level.
- Total practice sessions.
- Weekly practice activity.
- Progress report.
- Practice streak.
- Recent practice history.
- Quick action buttons.

3. ACADEMIC SPEAKING PAGE
- Scenario selection cards for classroom discussions, professor communication, group projects, and expressing opinions.
- Conversation interface with an AI professor or classmate.
- Microphone and text input visual controls.
- Conversation history area.

4. PRESENTATION SIMULATOR
- Script upload area.
- PPT/PDF upload area.
- Presentation topic input.
- Speaking timer.
- Start rehearsal button.

5. PROFESSOR Q&A PAGE
- Presentation topic input.
- Question difficulty selection.
- AI professor conversation layout.
- Answer area.

6. FEEDBACK REPORT PAGE
- Grammar.
- Vocabulary.
- Fluency.
- Pronunciation.
- Academic expressions.
- Answer organisation.
- Strengths and improvement suggestions.

7. GROUP PRESENTATION PAGE
- Create presentation room.
- Join room using code.
- Group member cards.
- Speaking section assignments.
- Shared script area.
- Presentation time allocation.

8. EXPRESSION LIBRARY
- Korean academic expressions.
- Categories for presentations, discussions, questions, and professor communication.
- Korean expressions with translated meanings.

9. PROFILE AND SETTINGS
- Profile information.
- Korean proficiency.
- Preferred interface language.
- Learning goals.

NAVIGATION:
Create a consistent sidebar with Dashboard, Academic Speaking, Presentation Simulator, Professor Q&A, Group Presentation, Expression Library, Practice History, and Settings.

LANGUAGE SUPPORT:
Prepare the interface structure for Korean, English, Simplified Chinese, Vietnamese, Indonesian, and Mongolian. Korean should remain the main learning language.

FUNCTIONALITY:
- Make navigation between all pages work.
- Make buttons and tabs interactive where possible.
- Use clearly labelled sample data for the initial design.
- Do not present simulated AI responses or sample scores as real results.
- Do not create non-functional buttons that appear to perform real actions.

Start by creating a polished landing page and dashboard, then build the remaining page layouts using the same design system.

Keep the code organised and reusable so we can connect authentication, a database, and AI features in later stages.
